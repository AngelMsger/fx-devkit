# Roadmap

These are potential extensions, not promises of current functionality.

## Team knowledge

- Store learnings beside Skills in the private manifest, with templates and
  contribution through `source push`.
- Add local Chinese-aware recall using Node standard APIs, stable JSON results
  and a retrieval Skill. No LLM calls or new runtime dependencies.
- Add opt-out local traces and aggregate statistics without prompt content or
  uploads.

## Conditional capabilities

- Consider session-end learning prompts after enough useful learnings exist and
  lifecycle hooks are stable.
- Track adoption and confidence only after reliable citation evidence exists.
- Add personal Skill selection when the shared collection warrants it.

# ロードマップ

以下は拡張の候補であり、実装済み機能の約束ではありません。既存のワークスペース、provider、Skill、ライフサイクル機能は維持します。

## チームの知識 {#team-knowledge}

- 非公開マニフェスト内で Skill と並べて知見を保存し、テンプレートと `source push` で貢献できるようにする。
- Node の標準 API、安定した JSON 出力、検索 Skill で中国語対応のローカル検索を追加する。LLM 呼び出しや新しいランタイム依存は追加しない。
- 無効化できるローカルトレースと集計統計を追加する。プロンプト本文やアップロードは含めない。

## 条件付きの機能 {#conditional-capabilities}

- 有用な知見が十分に蓄積され、ライフサイクルフックが安定してから、セッション終了時の振り返りを検討する。
- 引用の根拠が信頼できるようになってから、利用状況と確信度を追跡する。
- 共有 Skill 集合に必要性が生じた場合に、個人単位の Skill 選択を追加する。

# 変更履歴

## 未公開 {#unreleased}

fx ワークスペース CLI の初期ソースです。公開の告知ではなく、現在は内部配布を対象とし、一般公開は保留中で、ライセンスは Apache-2.0 に決定しています。プロジェクトは `fx-devkit`、npm パッケージは内部向け `@fx/devkit`、公開向け `@angelmsger/fx`、コマンドは `fx` です。

- 初期化時に不足している companion ツールを任意でインストール (`install_on_init`、fx ≥0.1.1)。
- マニフェストに基づく初期化、同期、リポジトリ選択。
- 構造化された設定、発見、準備状態、リリースレポート。
- 連携ツール、Agent Skill、ライフサイクルフック、MCP 投影。
- 信頼、所有権、復旧の境界を持つソース貢献計画。
- Windows ネイティブアダプター。[検証ガイド](docs/support.md)に受け入れ条件の制限を記載。

今後の項目では、このリポジトリでの変更を記録します。

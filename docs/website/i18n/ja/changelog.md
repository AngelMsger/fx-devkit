# 変更履歴

## 未公開 {#unreleased}

fx ワークスペース CLI の初期ソースです。公開の告知ではなく、一般配布は準備中で、ライセンスは Apache-2.0 に決定しています。プロジェクトは `fx-devkit`、予定 npm パッケージは `@angelmsger/fx`、コマンドは `fx` です。

- マニフェストに基づく初期化、同期、リポジトリ選択。
- 構造化された設定、発見、準備状態、リリースレポート。
- 連携ツール、Agent Skill、ライフサイクルフック、MCP 投影。
- 信頼、所有権、復旧の境界を持つソース貢献計画。
- Windows ネイティブアダプター。[検証ガイド](docs/validation.md)に受け入れ条件の制限を記載。

今後の項目では、このリポジトリでの変更を記録します。

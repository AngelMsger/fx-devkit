# 一般公開に向けた準備

プロジェクトは `fx-devkit`、npm パッケージは `@angelmsger/fx`、実行コマンドは `fx` です。リポジトリのバージョン番号だけでは、公開済みであることを証明できません。

## 配布の目標 {#distribution-target}

public npm で public access として公開します。fx のインストールにはプライベートレジストリ、チームアカウント、マニフェスト checkout を要求しません。チームのマニフェストと接続先サービスには、それぞれのアクセス制御が適用されます。

## 設定済みの公開先 {#configured-publication-coordinates}

oa-cli の公開パッケージの慣例に従い、以下の公開先を推定して設定します。

- リポジトリ：[AngelMsger/fx-devkit](https://github.com/AngelMsger/fx-devkit)。
- Web サイト：[fx-devkit](https://angelmsger.github.io/fx-devkit/)。
- 問題報告：[GitHub Issues](https://github.com/AngelMsger/fx-devkit/issues)。
- パッケージのアクセス：`public`。ライセンス：[Apache-2.0](../LICENSE)。

これらは設定上の公開先であり、リモート、Web サイト、npm バージョンが作成済みであることは示しません。サイトのソースは `docs/website/` にあります。npm 利用者向けの README は公開文書の URL を使います。サイトビルド時は自分自身の公開リンクを選択中の言語のローカルリンクに変換します。

## 残っている実装と決定事項 {#remaining-implementation-and-release-decisions}

- レジストリ方針、メタデータ取得、自己更新、公開 wrapper/guard、テストを一緒に移行します。現在は public npm を拒否するか、非公開の座標を要求します。[移行ガイド](design/registry-configuration.md)に対象を記載しています。
- 公開リポジトリを作成するときに、設定済みのリポジトリ、サイト、問題報告の宛先を確認します。公開前にパッケージ名、バージョン、`@angelmsger` スコープの権限を確認します。
- 実際の配布物に必要な第三者表記をレビューします。Apache-2.0 は選定済みで、ライセンス全文をパッケージに同梱します。
- 静的サイトには npm 公開と独立した GitHub Pages ワークフローがあります。パッケージ CI の通常チェックは、非公開資格情報とマニフェストへの依存をなくす必要があります。現在の Jenkins は全体で `npm-token` を使用し、`v*` タグで公開します。npm 公開前に認証とタグの扱いを調整してください。
- リポジトリとサイトの公開後に推定したリンクを確認します。npm パッケージに文書ソースとサイトツールは含めず、README から公開サイトやソースリポジトリへリンクします。
- 非公開の統合チェックと Windows の実機検証範囲は別に保ちます。オフラインテストを実ホストの検証結果として扱いません。

## ソースと配布物のレビュー {#source-and-artifact-review}

テスト、スクリプト、patch、シンボリックリンク、非テキスト資産を含む候補ファイルとパスを確認します。npm パッケージのみのスキャンでは不十分です。組織固有の検出辞書と未加工の結果は非公開に保管します。意味のある合成セキュリティテストを、単に削除してはいけません。

公開するすべての Git ref、コミットメッセージ、作者情報を確認してください。非公開の前身リポジトリの履歴をマージまたはミラーしません。移行対応表と原本は別の非公開記録に保管します。

[検証ガイド](validation.md)のチェックを実施し、source map と暗黙に含まれるファイルを含めた実際の npm tarball を調べ、隔離環境でインストールを確認します。ライセンス、メタデータ、レジストリ、CI の変更後は公開チェックを再実行します。

## 非公開データの境界 {#private-data-boundary}

共有座標、メンバー、チームの手順はマニフェストソースが管理します。過去の業務 patch、未加工の試行ログ、調査記録は適切に制限した保管先に置き、メンバー全員に配布されるマニフェストへ自動的に含めません。資格情報は元のツールに残します。

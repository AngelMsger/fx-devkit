# 路線圖

以下是可能的擴充方向，不是已實作功能的承諾。現有工作區、provider、Skill 和生命週期能力繼續保留。

## 團隊知識 {#team-knowledge}

- 在私有 manifest 中與 Skill 相鄰儲存經驗，透過範本與 `source push` 貢獻。
- 使用 Node 標準 API、穩定 JSON 輸出和檢索 Skill 實作支援中文的本機檢索，不引入 LLM 呼叫或新的執行階段相依套件。
- 新增可關閉的本機追蹤與彙整統計，不包含提示詞內容，不上傳資料。

## 需滿足條件的能力 {#conditional-capabilities}

- 有足夠有用經驗、且生命週期掛鉤穩定後，再考慮工作階段結束時的知識整理提示。
- 在引用證據可靠後，再追蹤使用情況與信賴度。
- 共用 Skill 集合確有需要時，再新增個人 Skill 選擇。

# 更新日誌

## 尚未發佈 {#unreleased}

fx 工作區 CLI 的初始原始碼基準。此處不是發佈公告，目前面向內部分發，公開發佈暫緩，授權條款已確定為 Apache-2.0。專案為 `fx-devkit`，內部 npm 套件為 `@fx/devkit`，公開 npm 套件為 `@angelmsger/fx`，命令為 `fx`。

- 支援在初始化時依宣告安裝缺少的配套工具（`install_on_init`，fx ≥0.1.1）。
- Manifest 驅動的工作區初始化、同步與儲存庫選擇。
- 結構化設定、探索、就緒和發佈報告。
- 配套工具整合、Agent Skill、生命週期掛鉤與 MCP 投射。
- 具備信任、擁有權和復原界線的共用來源貢獻計畫。
- 原生 Windows 介接器，驗收限制請參閱[驗證指南](docs/support.md)。

後續項目記錄本儲存庫中的變更。

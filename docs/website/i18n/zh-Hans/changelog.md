# 更新日志

## 尚未发布 {#unreleased}

fx 工作区 CLI 的初始源码基线。此处不是发布公告，当前面向内部分发，公开发布暂缓，许可证已确定为 Apache-2.0。项目为 `fx-devkit`，内部 npm 包为 `@fx/devkit`，公开 npm 包为 `@angelmsger/fx`，命令为 `fx`。

- 支持在初始化时按声明安装缺失的配套工具（`install_on_init`，fx ≥0.1.1）。
- Manifest 驱动的工作区初始化、同步与仓库选择。
- 结构化配置、发现、就绪和发布报告。
- 配套工具集成、Agent Skill、生命周期钩子与 MCP 投射。
- 具备信任、所有权和恢复边界的共享源贡献计划。
- 原生 Windows 适配器，验收限制见[验证指南](docs/support.md)。

# 路线图

以下是可能的扩展方向，不是已实现功能的承诺。现有工作区、provider、Skill 和生命周期能力继续保留。

## 团队知识 {#team-knowledge}

- 在私有 manifest 中与 Skill 相邻保存经验，通过模板与 `source push` 贡献。
- 用 Node 标准 API、稳定 JSON 输出和检索 Skill 实现支持中文的本地召回，不引入 LLM 调用或新的运行时依赖。
- 增加可关闭的本地追踪与汇总统计，不包含提示词内容，不上传数据。

## 需满足条件的能力 {#conditional-capabilities}

- 有足够有用经验、且生命周期钩子稳定后，再考虑会话结束时的知识整理提示。
- 在引用证据可靠后，再追踪使用情况与置信度。
- 共享 Skill 集合确有需要时，再增加个人 Skill 选择。

# Changelog

## Unreleased

Initial source baseline for the `fx` workspace CLI. This is not a publication
announcement; distribution is internal and public release is on hold. The project uses Apache-2.0.
The project is `fx-devkit` and the binary is `fx`. Internal distribution uses
`@fx/devkit`; public distribution uses `@angelmsger/fx`.

- Manifest-driven workspace initialization, synchronization and repository selection.
- Structured configuration, discovery, readiness and release reports.
- Companion tool integration, agent Skills, lifecycle hooks and MCP projections.
- Source contribution planning with trust, ownership and recovery boundaries.
- Native Windows adapters with acceptance limits documented in
  [platform support](https://angelmsger.github.io/fx-devkit/docs/support/#platform-support).

Future entries describe changes made in this repository.

# Security reporting

fx-devkit is currently distributed internally. Report security findings privately
to the team maintainers through the internal security/support channel. Include the
version, affected behavior, a redacted reproduction and impact. Do not place
credentials, private manifests, personal information or real service coordinates
in a shared issue or reproduction fixture.

Keep dependencies current and preserve the package and user-documentation boundary
checks. See [data and credentials](docs/user-privacy.md) for user responsibilities.
